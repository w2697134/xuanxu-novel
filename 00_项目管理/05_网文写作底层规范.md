# 网文写作底层规范

状态：v0.1 准定稿

> 强制规则：以后写任何正文、重写、续写、润色之前，必须先读本文件。
>
> 本文件优先级高于临时聊天判断。正文不符合本文件时，先改正文，不解释。

## 一、核心判断

本项目不是按纸质书写，也不是按电脑 Markdown 预览写。

本项目默认读者在手机端阅读，而且很可能使用较大字号。

所以正文必须服务手机网文阅读体验：

- 前几屏必须抓人。
- 段落必须短。
- 信息必须拆开。
- 对话必须独立。
- 设定必须跟着事件走。
- 每章必须给小回报和下一章拉力。

## 二、开局不是“慢慢铺”，而是先给 promise

网文开头的第一任务不是展示文笔，而是让读者知道：

1. 主角是谁。
2. 主角正在做什么。
3. 现在出了什么事。
4. 为什么这件事值得继续读。
5. 这本书后续主要卖什么情绪价值。

本项目核心卖点是：

- 修仙主线。
- 现实异常切入。
- 认知被篡改、异常被正常化的悬疑感。
- 主角团互相托底的真实情感。
- 从现实青年被抛入修真世界后的求生、修行和破局。

因此，第一章不能从长环境、长设定、长职业说明开始。

第一章应该从“主角正在做一个可能导致异常被掩盖的动作”开始。

## 三、前1屏 / 前3屏 / 前5屏规则

### 前1屏

必须完成：

- 主角出场。
- 异常、风险、冲突至少出现一个。
- 读者知道“有事发生”。

不合格开头：

- 纯环境描写。
- 纯背景说明。
- 纯职业流程。
- 读者看完第一屏还不知道危险在哪里。

### 前3屏

必须完成：

- 当前风险变清楚。
- 至少出现一个关系位，例如韩铮阻止江彻、林序介入判断。
- 出现第一个选择、阻止、证据或反常现象。

### 前5屏

必须完成：

- 出现第一份硬证据、小反转或阶段性回报。
- 读者明确知道为什么要继续看这一章。

## 四、适合本项目的开局钩子类型

### 最适合：危机动作钩子

主角正在做一件看似普通但后果很大的事。

例如：

> 江彻第七次把鼠标移到“确认正常”上。
>
> 只差一下，QH-17-4就会第三十七次被归档成盐壳裂纹。

优点：

- 主角立刻出场。
- 行动明确。
- 风险明确。
- “第三十七次”天然产生追问。

### 次适合：对话打断钩子

有人突然阻止主角。

例如：

> “你他妈别点。”

优点：

- 关系立刻出现。
- 情绪立刻出现。
- 读者想知道为什么不能点。

### 不优先：新闻播报 / 档案 / 系统日志

这些可以作为辅助信息，但不适合作为主开头。

原因：

- 主角缺席。
- 容易像设定资料。
- 读者可能直接滑过。
- 不如“主角正在犯错”抓人。

## 五、手机网文段落规范

本项目正文按手机大字阅读设计。

纸书里一两行，手机上可能是五六行，所以段落必须短。

### 字数标准

- 普通叙述段：20—60字。
- 重点氛围段：10—40字。
- 信息说明段：最多80字。
- 超过100字：必须人工复核。
- 超过120字：必须拆。

### 视觉标准

- 一段最好是手机2—4行。
- 一屏最好有3—6个自然段。
- 不允许一段占半屏。
- 不允许连续长段压住读者。

### 排版规则

- 不首行缩进。
- 段落之间空一行。
- 对话一句一段。
- 动作、反应、心理、信息点分开。
- 关键句单独成段。
- 不用连续多个空白行硬撑篇幅。

## 六、设定释放规则

设定必须跟着事件走。

不要先解释世界观，再让剧情发生。

正确顺序：

1. 主角遇到问题。
2. 主角尝试解决。
3. 出现异常结果。
4. 读者产生疑问。
5. 再给一点必要解释。

错误顺序：

1. 先讲项目背景。
2. 先讲技术流程。
3. 先讲地理设定。
4. 先讲世界观规则。
5. 读者还没看到事，就先被说明文压住。

## 七、每章必须有小闭环

每章至少完成一轮：

目标 → 阻碍 → 推进 / 回报 / 代价。

不能只铺氛围。

不能只留悬念。

不能只讲设定。

每章结尾必须有下一章拉力。

拉力可以是：

- 新危险。
- 新证据。
- 新人物介入。
- 主角做出不可逆选择。
- 旧判断被推翻。

## 八、对话规则

对话不是聊天记录。

每段对话至少承担一个功能：

- 推进情节。
- 展示关系。
- 抬高冲突。
- 暴露信息差。
- 触发行动。
- 形成反差。

没有功能的对话删掉。

韩铮的嘴碎可以保留，但必须服务人物关系、缓冲压迫感或推动行动。

林序的理性可以保留，但不能写成长篇解释机器。

## 九、本项目当前正文问题

当前第1—5章存在两个问题：

1. 开头进入太慢，第一章应改为危机动作钩子。
2. 部分段落仍偏长，应继续按手机网文规则拆短。

因此，当前启动策略不是继续盲写第6—10章。

当前启动策略是：

1. 重构第一章开头。
2. 保留原有氛围和人物关系。
3. 把“确认正常”“第三十七次”“不要相信明天的我”前置到第一屏。
4. 之后再统一审第1—5章是否符合手机段落规范。
5. 再继续写第6—10章。

## 十、写前强制卡

以后任何新章节开写前，先填这张卡。

- 章节名：
- 本章一句话：
- 本章卖点：
- 首屏钩子类型：
- 主角此刻正在做什么：
- 第一处异常 / 冲突：
- 前3屏要交代清楚的事：
- 本章小回报：
- 章尾拉力：

没填卡，不开写。

## 十一、提交前检查

正文提交前必须检查：

- 第一屏是否有主角。
- 第一屏是否有异常 / 冲突 / 风险。
- 前3屏是否有明确问题。
- 前5屏是否有小回报或硬证据。
- 是否有超过100字的长段。
- 对话是否独立成段。
- 章尾是否有继续读的理由。
- 是否有设定说明抢在事件前面。

## 十二、一句话记忆版

先出事，再解释。

先抓人，再铺垫。

短段落，手机优先。

每章有回报，章尾有拉力。

不要相信“慢慢来”，除非第一屏已经把读者抓住。
