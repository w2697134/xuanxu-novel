# 正文排版规范

状态：v0.1 准定稿

## 核心原则

本项目正文采用适合手机和网页阅读的小说排版：

- 不首行缩进。
- 段落之间空一行。
- 多切短段，不写大块长段。
- 对话单独成段。
- 动作、心理、信息点尽量拆开。
- 不用连续多个空白行硬撑版面。

## 为什么这样排

正文需要读起来松，尤其在手机屏幕上，长段会形成压迫感。

但仓库中的 Markdown 文件不应该堆大量空行。多余空行会污染 GitHub diff，也不利于后续版本管理。

因此，本项目的“松”不是靠空白行堆出来，而是靠：

1. 短段落。
2. 对话独立。
3. 信息点分层。
4. 节奏处自然换段。

## 推荐段落长度

普通叙述段：1—3行视觉长度。

长信息段：尽量拆成两段以上。

对话：一句话一段。

关键心理或异常感知：可以单独成段。

## 禁止做法

- 不要每个段落之间插入两个以上空白行。
- 不要为了凑篇幅硬塞空行。
- 不要把整段解释写成说明文块。
- 不要一章里出现大段密集设定说明。
