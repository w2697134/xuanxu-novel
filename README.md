# 玄墟小说项目

状态：v0.1 初始化

这是一个长期小说项目仓库，用于维护世界观、人物、修行体系、剧情章纲、术语表和废案记录。

## 当前定位

长篇玄幻修仙为主，科幻悬疑作为骨架、质感和解释层。地球与修真界是相互独立的世界，地球可以极其特殊，但不是修真界附属、分支或下位世界。

## 当前核心原则

- 修仙是主线，科幻是谜团、认知方式和底层机制。
- 开局写现实世界，但不能拖成长期地球科研篇。
- 第一卷写到修仙刚起步。
- 江彻是唯一核心主角，但允许队友在必要场景拥有高光视角。
- 避免过度分流：队伍可以长期离队，但叙事重心不能散。
- 后宫可以有，但不是主要剧情，不写成感情收集。
- 核心队友不允许廉价背叛；若有伪背叛或被迫站到对立面，必须服务更强剧情。
- 核心队友只能在大后期死亡，而且死亡必须具备整部书级别的情感和局势重量。

## 目录

- `设定库/`：项目总览、世界结构、叙事规则、修行体系、术语表。
- `人物/`：主角团与重要人物档案。
- `剧情/`：分卷定位与章纲。
- `管理/`：版本规则与入仓说明。
- `废案/`：已覆盖或暂不采用的设定。
